# Customer Service Guide
AI-powered customer service assistant project.

## Features
- Chatbot support
- AI response generation
- FastAPI backend
- Modern frontend

## Installation

```bash
git clone <repo-url>
cd project
```

## Run Backend

```bash
pip install -r requirements.txt
cd backend
uvicorn main:app --reload
```

# Run Frontend

```bash
cd frontend
node server.js
```


## Tech Stack
- Python
- FastAPI (backend)
- Node.js (frontend)
- HTML/CSS/Javascript
- LangChain
- ChromaDB
- Sentencetransformers (all-MiniLM-L6-v2)
- Groq API call
- llama-3.1-8b-instant (LLM)
